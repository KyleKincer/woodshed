Woodshed 1.3.0 adds richer song details and a redesigned settings experience.

- Edit song titles, artists, albums, artwork, release details, genre, and practice notes from the library or player.
- Edit multiple songs at once, changing only the fields you select.
- Keep your corrections when reprocessing audio or applying catalog suggestions.
- Find recordings and cover artwork through MusicBrainz when online lookup is enabled. Metadata service availability depends on deployment configuration.
- Built-in audio fingerprint generation helps identify new imports without uploading audio to the metadata provider.
- Redesigned settings and simpler desktop account connection replace manual browser pairing.
- Cleaner form spacing, fewer redundant instructions, and a compact pencil button in the player.

The web app is available at https://woodshed.kylekincer.com. Existing desktop users can check for updates from the app menu.

Choose `.dmg` for macOS (arm64 for Apple Silicon, x64 for Intel), `.exe` for Windows, or `.AppImage` for Linux. Windows is unsigned. Make the Linux AppImage executable before opening it. Processing model weights download on first use.
