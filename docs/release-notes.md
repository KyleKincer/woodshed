Woodshed 1.4.0 makes navigating, configuring, and using the app feel smoother and more immediate.

- Adds quick, restrained transitions between the library and songs, with the wordmark and header controls moving into place. Library layout changes, buttons, menus, dialogs, and notifications share the same subtle motion. Respects reduced-motion preferences.
- Adds a back chevron beside Woodshed in songs, Settings, Plan & billing, and Administration to return to the library. Supports keyboard navigation and narrow screens.
- Simplifies separation quality settings with a Fast / Balanced / Studio slider and expandable advanced controls. Advanced values reflect the selected preset.
- Refines Settings with clearer storage and cache controls, app version information, and progress and error feedback for actions.
- Makes monthly and yearly Plus billing easier to compare, with a single checkout button and clearer progress during billing and library exports.
- Keeps the account button compact with just the avatar. Improves pointer and keyboard behavior so clicking a control does not leave it armed for the next Space press, while useful text remains selectable.
- Handles rapid navigation safely and keeps audio loading independent of navigation animations.

Existing desktop users can select **Check for Updates** from Settings or the Woodshed menu once this release is published.

Choose `.dmg` for macOS (arm64 for Apple Silicon, x64 for Intel), `.exe` for Windows, or `.AppImage` for Linux. Windows is unsigned. Make the Linux AppImage executable before opening it. Processing model weights download on first use.
