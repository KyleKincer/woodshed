Woodshed 1.2.0 brings a refreshed interface to the web and desktop apps.

- A cobalt header, warm background, larger artwork, and clearer library controls.
- A stacked waveform player with dedicated playback, zoom, loop, and metronome controls. Existing mute, solo, and practice tools remain available.
- Google account avatars, a standard settings icon, and sign-in notices that do not move the page layout.
- More accessible keyboard navigation, dialogs, and control labels.
- Responsive playback controls and artwork fallbacks when a song has no cover image.

The web app is available at https://woodshed.kylekincer.com. Existing desktop users can check for updates from the app menu.

Choose `.dmg` for macOS (arm64 for Apple Silicon, x64 for Intel), `.exe` for Windows, or `.AppImage` for Linux. Windows is unsigned. Make the Linux AppImage executable before opening it. Processing model weights download on first use.
